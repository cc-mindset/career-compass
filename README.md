# HOW TO GET THE FULL STACK APP RUNNING

# Spin Up The Front End (client)
- Add FE Env Variables
- Run npm i
- Run npm run dev
- The FE should be running on port 5173

# Spin Up The Back End (web-server)
-Download Docker run: docker run -d --name clarity-coach-redis -p 6379:6379 redis
- Add BE Env Variables
- Run npm i
- Run npm run dev
- The BE should be running on port 5001
